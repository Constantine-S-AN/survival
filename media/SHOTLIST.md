# Screenshot Shotlist (Required 3)

以下 3 张是仓库展示的最低配置，文件名建议固定，方便 README 引用。

## 1) `media/shot_main_menu.png`
- 场景：主菜单或开局选择流（角色/地图/契约）
- 目的：让访客第一眼知道这是“可构筑 + 可选择开局”的作品
- 构图建议：UI 清晰、标题可见、避免调试面板遮挡

## 2) `media/shot_combat_fog_sonar_noise.png`
- 场景：中期战斗，屏幕中同时出现 Fog、声呐波纹、噪声条
- 目的：一图说明本作核心差异轴（信息与代价）
- 构图建议：敌群与玩家位置有层次，尽量包含追猎压力信号

## 3) `media/shot_upgrade_choice.png`
- 场景：三选一升级界面
- 目的：展示构筑深度（Tag、目标对象、关键数值变化）
- 构图建议：卡面信息完整可读，至少一张卡显示“影响武器/Tag”

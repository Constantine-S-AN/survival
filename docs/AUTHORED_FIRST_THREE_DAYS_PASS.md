# Authored First Three Days Pass

## Opening Experience Goals

This pass pushes the first three in-game days away from a polished sandbox opening and toward a more intentional authored ramp. The goal was to keep the same systems and routing, but make the player feel gently directed through a sequence of meaningful beats:

- Day 1: establish the farm, prove the restaurant matters, then leave from the dock with purpose.
- Day 2: understand that last night's haul changes daylight choices.
- Day 3: feel the full loop starting to reinforce itself across harvests, service, orders, shop decisions, and the next launch.

## Friction / Flatness Identified

- Day 1 guidance still read like a flexible checklist instead of a clear opening lane.
- Only the first morning had a strong authored dialogue beat; Days 2 and 3 returned to mostly systemic guidance.
- Return-summary text explained rewards, but it did not frame early rewards as part of a growing authored arc strongly enough.
- Shop NPC lines and request chatter were functional but too generic to help sell the first-three-day progression.
- Early restaurant payoff existed mechanically, but the authored follow-through after the first strong lunch beat was thin.

## What Was Improved

- Added day-specific morning dialogue beats for Days 2 and 3, while preserving the existing Day 1 intro behavior.
- Reworked Day 1 guide logic into a clearer authored lane:
  - start with starter plots
  - move into the first restaurant proof beat
  - hand the player off to the dock
- Tightened Day 2 and Day 3 guide copy so it frames rewards and choices more like an authored progression than neutral UI instruction.
- Made early return-summary copy more day-aware so the first and second returns better explain why tomorrow is different.
- Added stronger first-three-day shopkeeper and town-regular lines so the shop reads as part of the authored loop rather than a generic utility stop.
- Refined the first strong restaurant customer follow-up line so it better reinforces the room as a real daytime anchor.
- Updated board-facing “featured” phrasing to read more like opening leads than generic starter markers.

## First-Three-Day Acceptance Note

- Day 1 now frames a cleaner authored lane: farm first, Field Stew proof beat second, dock departure third.
- Day 2 now explicitly frames the first return haul as something that should change daylight choices immediately.
- Day 3 now reinforces that harvests, restaurant service, orders, and night rewards are finally compounding together.
- Morning dialogue, guide copy, shop chatter, and return-summary text now support the same authored arc instead of feeling like separate systems.

## Deferred

- No new cutscene flow or large scripted event chains were added.
- Daily order mechanics and assignment logic were not rewritten; this pass only strengthened the authored framing around them.
- Later-day authored progression beyond Day 3 is still deferred.
- No economy, reward, inventory, or save architecture changes were made.
